# NeuRGCL: Neural Robot Geometry for Real-time Collision Avoidance Library

This repository provides the PyTorch implementation of **NeuRGCL** (referred to as **NSDF** in the code). The CUDA-accelerated implementation of NeuRGCL will be made publicly available upon acceptance.

🎞️ A demo of the collision-avoidance experiments in simulation and on a real robot can be found in this [video](https://drive.google.com/file/d/1b4E_DCML_1zI4wbJf9qqz-QfmVTWYPks/view?usp=drive_link).

## 1. Setup environment

Please follow the steps below to set up the environment. [See here for details🔗](cmds/01_setup_env.sh)

``` bash
# Create conda environment and install dependencies. This may take >20 minutes to install (including building cuRobo).
bash cmds/01_setup_env.sh
```

## 2. Train NeuRG (Optional)

We provide a pretrained NeuRG model for the Franka Panda in `logs/link_infos/softplus_coll_32x3.pth`. If you want to train your own NeuRG models, follow the steps below.

``` bash
conda activate neurg

# a. generate dataset
bash cmds/02_gen_dataset.sh

# b. train NeuGs (Note: delete or rename the existing "lightning_logs/nsdf" folder before training.)
bash cmds/03_train_neugs.sh

# c. convert NeuGs to NeuRG
bash cmds/04_compose_to_neurg.sh
```

## 3. Run the *Moving Spheres* Experiment with QP controller
This runs the experiment using three methods: NSDF (ours — PyTorch NeuRG), JSDF, and RDF.

``` bash
conda activate neurg
bash cmds/run.sh
```

Recorded videos can be found in the folder: `logs/qpik/dyna_ball/`.

## Detailed Code Explanation

### Large pre-generated datasets
Large pre-generated datasets are hosted on Google Drive to keep the repository lightweight:  
[https://drive.google.com/drive/folders/1aI5pzOnZ03_EcbJFRqWQJSiJYkj6qDZn?usp=sharing](https://drive.google.com/drive/folders/1aI5pzOnZ03_EcbJFRqWQJSiJYkj6qDZn?usp=sharing)

### Preparation

1. Set up development environment: [cmds/01_setup_env.sh](cmds/01_setup_env.sh)
2. Generate the dataset from URDF: [cmds/02_gen_dataset.sh](cmds/02_gen_dataset.sh)
3. Training NeuGs: [cmds/03_train_neugs.sh](cmds/03_train_neugs.sh)
4. Compose NeuGs to NeuRG: [cmds/04_compose_to_neurg.sh](cmds/04_compose_to_neurg.sh)
5. (Optional, included in repo) Prepare evaluation dataset for JSDF's test data, i.e., `data/baselines/jsdf/d_test_grad.pkl`:
    1. Download the pre-generated JSDF dataset with the same meshes as ours:  
    [cmds/05_download_jsdf_dataset.sh](cmds/05_download_jsdf_dataset.sh)
    2. Generate gradient dataset for JSDF's test data:  
    [python src/neurg/scripts/gen_ds_jsdf_grad.py](src/neurg/scripts/gen_ds_jsdf_grad.py)
6. Run the QP controller with JSDF, RDF, and NSDF (ours, NeuRG's PyTorch Version) methods in the *Moving Spheres* simulation: [python src/qp_ik/demo/dyna_ball.py](src/qp_ik/demo/dyna_ball.py)

⚠️Note: Before run any python programs, prepare the environment:

    ```bash
    conda activate neurg
    source ./cmds/env_vars.sh
    ```

### APIs

1. **NSDFLModel** (**NeuG**'s PyTorch version, single link) [src/neurg/api/nsdf_model.py](src/neurg/api/nsdf_model.py)
    - ✅Local Distance Query  `l_dist`
2. **NSDFModel** (**NeuRG**'s PyTorch version, multi-link robot)  
[src/neurg/api/nsdf_model.py](src/neurg/api/nsdf_model.py)
    - ✅Local Distance Query `l_dist`
    - ✅Global Distance Query `g_dist`
    - ✅Self-collision Query `sc_dist`
3. 🟩 Cuda-accelerated **NeuG** and **NeuRG** implementations will be released after acceptance.

### Evaluation

1. Single link
    1. Distance error: evaluate distance error on ours test dataset  
    [python src/neurg/eval/eval_neug_link_err.py](src/neurg/eval/eval_neug_link_err.py) 

    2. Surface-point gradient error  
    [python src/neurg/eval/eval_neug_surface_normal.py](src/neurg/eval/eval_neug_surface_normal.py)  
    Prerequisite: `logs/nsdf/dataset/surface_normal/100000.pkl` (generated by `python src/neurg/scripts/gen_ds_surface_normal.py --n_sample=100000`, or download from [here](https://drive.google.com/file/d/1hqUubKuoYZrE5otXoOaoi6rtSUWs72o8/view?usp=sharing))

    3. Efficiency: query time for a single-link NeuG with different batch sizes  
    [python src/neurg/eval/eval_time_neug.py](src/neurg/eval/eval_time_neug.py)

2. Robot-level
    1. Error of distance and its gradient w.r.t. local points on JSDF's test dataset  
    [python src/neurg/eval/eval_err_on_jsdf.py](src/neurg/eval/eval_err_on_jsdf.py)  
    Prerequisite: `data/baselines/jsdf/d_test_grad.pkl`

    2. Query efficiency comparison  
    [python src/neurg/eval/eval_time_1qpts.py](src/neurg/eval/eval_time_1qpts.py)
